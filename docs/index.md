# CVBench

### A GPU-enabled computer vision training sandbox — Keras + TensorFlow + JupyterLab in one container.

Train, evaluate, and serve classification and detection models from one CLI and
one WebUI, without wiring up your own training scaffolding.

[Get started](quickstart.md){ .md-button .md-button--primary }
[View on GitHub](https://github.com/mmgalushka/cvbench){ .md-button }

</div>

<div class="grid cards" markdown>

-   :material-brain:{ .lg .middle } **Train**

    ---

    Train classification and detection models with augmentation,
    optimizer/loss options, and two-phase fine-tuning built in.

-   :material-chart-box-outline:{ .lg .middle } **Evaluate**

    ---

    Score any run on its held-out test split — per-class metrics, confusion
    matrices, and detection outcome tables.

-   :material-target:{ .lg .middle } **Predict**

    ---

    Run inference on new images with a trained experiment, from the CLI or
    the WebUI.

-   :material-monitor-dashboard:{ .lg .middle } **Serve**

    ---

    Browse every run, compare experiments, and inspect predictions in a
    built-in WebUI — no separate deployment needed.

</div>
